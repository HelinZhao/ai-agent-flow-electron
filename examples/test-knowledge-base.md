# AI Agent Flow Designer 产品文档

## 产品概述

AI Agent Flow Designer 是一款基于 Electron 的可视化工作流设计工具，旨在帮助用户通过拖拽节点的方式构建 AI Agent 工作流，无需编写代码即可实现复杂的自动化任务。

核心设计理念是「所见即所得」——用户在画布上连接各个节点，定义数据流向和处理逻辑，系统自动按流程执行并返回结果。

## 主要功能模块

### 工作流画布

画布是产品的核心交互区域，支持以下操作：

- 拖拽添加节点：从左侧工具栏拖拽节点类型到画布
- 连线：点击节点输出端口拖向另一节点输入端口，建立数据流
- 节点配置：双击节点打开配置面板，设置参数
- 一键布局：使用 dagre 算法自动排列节点位置
- 缩放和平移：鼠标滚轮缩放，拖拽画布平移

### 支持的节点类型

| 节点类型 | 功能说明 |
|---------|---------|
| 开始节点 (Start) | 工作流入口，接收用户输入，可定义参数 |
| LLM节点 (LLM) | 调用大语言模型，支持工具调用和知识库增强 |
| 技能节点 (Skill) | 调用预定义的技能模板 |
| 文本节点 (Text) | 模板渲染 + 变量替换，不调用 LLM |
| 代码节点 (Code) | 运行 JavaScript 代码 |
| 条件节点 (If) | JS 表达式多条件分支，无需 LLM |
| 分支节点 (Branch) | LLM 语义评估条件分支 |
| API节点 (API) | 调用外部 HTTP API |
| 数据库节点 (Database) | 查询 SQLite/PostgreSQL/MySQL/MongoDB/Redis |
| 知识库检索 (Knowledge) | 向量检索知识库获取上下文 |
| MCP节点 (MCP) | 调用 MCP 协议工具 |
| Agent节点 (Agent) | 调用预配置的智能体 |
| 子工作流 (SubWorkflow) | 嵌套执行另一个工作流 |
| 变量节点 (Variable) | 设置/获取工作流变量 |
| 循环节点 (Loop) | 迭代执行子工作流 |
| 拆分节点 (Split) | 拆分数据并行处理 |
| 聚合节点 (Merge) | 合并多路输出 |
| 转换节点 (Transform) | JSON 数据转换 |
| 睡眠节点 (Sleep) | 延迟执行 |
| CLI节点 (CLI) | 执行命令行指令 |
| 结束节点 (End) | 工作流出口，返回结果 |
| 错误处理 (Catch) | 捕获失败节点错误 |
| 注释节点 (Note) | 纯可视化注释 |

### LLM 节点配置

LLM 节点是使用最频繁的节点类型，支持以下配置项：

- 提示词模板：定义发送给 LLM 的提示词，支持变量插值 {{variableName}} 和 {{$input}}、{{$params.xxx}}、{{$nodes["id"].output}} 等系统变量
- 变量配置：定义模板中的动态变量，支持字符串、数字、布尔、数组类型
- 工具调用：勾选后 LLM 可自主调用文件读写、命令执行、HTTP请求、网页搜索、内部 API 等工具
- 技能绑定：绑定已创建技能作为 system prompt
- 知识库增强：启用后自动从知识库检索相关内容注入提示词，实现 RAG
- 响应格式：支持 text / json_object 输出格式
- 缓存开关：相同 prompt 重复调用时直接返回缓存结果

### 条件节点 (If)

条件节点使用 JS 布尔表达式进行条件判断，无需 LLM 参与。支持多个条件分支，从上到下依次求值，返回第一个为 true 的分支。

- 条件表达式支持模板变量（$input、$params.xxx 等）
- 每个条件可设置分支标签，用于标识连线
- 所有条件不满足时走默认路径
- 不调用 LLM，执行速度快

### 分支节点

分支节点支持多条件判断。系统会使用 LLM 对用户输入进行语义评估，匹配到哪个条件就走哪条路径。每个分支需要定义：

- 条件描述：用自然语言描述满足条件的情况
- 条件标签：分支的显示名称

### 变量节点 (Variable)

变量节点支持两种操作模式：

- **设置变量**：定义变量名和值，值支持模板变量。设置后下游节点可通过 {{$vars.变量名}} 引用
- **获取变量**：按名称取出已设置的变量值，输出 JSON

变量节点提供跨节点的数据共享能力，替代手动使用 {{$nodes["id"].output}} 引用。

### 数据库节点 (Database)

支持六种数据库类型的查询和操作：

- **SQLite**：本地文件数据库，路径支持 {{$env.DB_PATH}}
- **PostgreSQL / MySQL / SQL Server**：连接字符串格式 connectionString
- **MongoDB**：支持 find/aggregate/findOne/insertOne/updateOne/deleteOne/count 等操作
- **Redis**：支持任意 Redis 命令，如 GET/SET/DEL/LPUSH 等

SQL 语句和连接配置均支持模板变量解析。query 模式仅允许 SELECT 语句。

### 知识库检索节点 (Knowledge)

向量检索知识库，将结果传递给下游 LLM 节点：

- **知识库选择**：从已创建的知识库中选择
- **检索查询**：支持 {{$input}} 等模板变量作为搜索关键词
- **Top K**：返回的结果数量

### CLI 节点

CLI 节点支持两种模式：

1. 自定义命令：直接输入 shell 命令，支持 {{$input}} 等变量替换
2. 预设模板：使用系统内置的文件操作模板

命令输出有两种处理方式：

- 原始输出：直接将 stdout/stderr 传递给下游
- LLM 处理：将命令输出交给 LLM 分析提取关键信息

### 模板变量系统

所有支持文本模板的位置通用以下变量：

| 变量 | 说明 |
|------|------|
| {{$input}} | 当前节点接收到的上游输入 |
| {{$params.xxx}} / {{$params.xxx.yyy}} | Start 节点定义的参数，支持点号路径 |
| {{$nodes["id"].output}} | 引用任意已完成节点的输出 |
| {{$env.xxx}} | 工作流级环境变量 |
| {{$global.xxx}} | 全局环境变量（设置页管理） |
| {{$vars.xxx}} | 工作流变量（由 Variable 节点设置） |
| {{$now}} / {{$now.iso}} | 当前 ISO 时间 |
| {{$now.date}} / {{$now.time}} | 日期 YYYY-MM-DD / 时间 HH:mm:ss |
| {{$now.timestamp}} | 毫秒时间戳 |
| {{$params.a + $params.b}} | 支持 JS 表达式运算（加法、拼接、toUpperCase 等） |

可用范围：LLM 节点 prompt、Text 节点文本、API 配置 URL/headers/body、CLI 命令、MCP 参数、条件表达式、代码节点等。

### 知识库功能

知识库支持两种类型：

- **内部知识库**：上传 txt/md 文档，系统自动分块、生成 embedding 向量、存入 sqlite-vec，检索时用向量相似度搜索返回最相关的片段
- **外部知识库**：配置第三方检索 API，支持 Dify、百炼、千帆、AnythingLLM、FastGPT、RAGFlow 等

内部知识库的配置参数：

- 分块大小：文档切分的字符数（默认 500），影响检索精度和语义完整性
- 分块重叠：相邻分块的重叠字符数（默认 50），防止关键信息被切断
- 检索数量 topK：每次查询返回的最大分块数（默认 3）

### 模板市场

模板市场提供预构建的集成模板，按类型分类：

- **API 模板**：Slack、飞书、GitHub Issue、Telegram、天气查询、翻译等
- **MCP 配置**：Playwright、Filesystem、GitHub、SQLite、MySQL、Redis、小红书、抖音等
- **代码片段**：JSON 转 CSV、数据统计、文本分块、Base64 编解码、HTTP 请求封装等
- **技能模板**：代码审查、Prompt 优化、SQL 生成、翻译助手、数据分析等
- **工作流模板**：内容审核、每日热点简报等
- **Agent 模板**：客服助手、代码审查员、写作助手、数据分析师、学习导师等

MCP 模板点击「添加」直接安装，工作流/Agent/技能模板点击「导入」一键创建。

### 触发器系统

支持两种触发器类型，实现工作流自动调度：

- **Cron 定时触发**：6 段 Quartz 格式（秒 分 时 日 月 周），含可视化编辑器和预设模板
- **Webhook 触发**：创建后生成唯一 URL，POST 请求触发。限流：同 token 每分钟 10 次

每个触发器可配置执行目标（工作流或 Agent），支持自定义输入参数和启用/禁用控制。

### 环境变量

- **工作流级 ($env)**：在编辑器「环境变量」按钮配置，仅当前工作流可见
- **全局级 ($global)**：在设置 → 环境变量页面管理，所有工作流共享

### 重试机制

每个节点可配置重试策略：

- retryCount：失败重试次数（默认 0）
- retryDelay：重试间隔毫秒（默认 1000）
- retryBackoff：退避策略（fixed / exponential）

### 模板市场

模板市场提供预构建的集成模板，覆盖 API 集成、MCP 配置、代码片段、技能、工作流和 Agent。

## 设置页面

设置页面包含：

1. **模型配置**：管理 LLM API 配置（OpenAI / Anthropic / Azure / 百炼 / DeepSeek / LongCat / Ollama），支持多配置切换和连接测试
2. **环境变量**：管理全局环境变量，所有工作流可通过 {{$global.xxx}} 引用
3. **代理配置**：配置 HTTP/HTTPS/SOCKS5 代理
4. **MCP 服务器**：管理 MCP 服务器连接
5. **外观主题**：切换深色/浅色 UI 主题
6. **数据管理**：导出/导入工作流 JSON，VACUUM 回收数据库空间

## 对话与执行

### 工作流执行

点击工作流的运行按钮，弹出参数表单填写 Start 节点定义的参数和附加文本输入，系统按节点顺序依次执行。

- **参数表单**：如果 Start 节点定义了参数，执行前弹出参数填写界面
- **参数类型**：字符串、数字、布尔、数组，可设置必填和默认值
- **参数引用**：下游节点通过 {{$params.xxx}} 引用参数值

### Agent 对话

为 Agent 配置工作流后，对话界面支持：

- 多轮对话上下文记忆
- 附件上传（图片、文本、PDF），自动注入 LLM
- Agent 可绑定工作流或直接对话（无工作流模式）
- 对话历史持久化存储

### 执行监控

执行过程中可以实时查看：

- 当前执行的节点
- 各节点的执行状态（运行中/完成/失败）
- 执行进度百分比
- 节点耗时和输出日志
- 执行路径（节点执行顺序）
- 按状态筛选运行记录

### 节点测试

右键任意节点选择「测试」，输入测试数据即可查看该节点的执行结果，无需运行整个工作流。

### 工具审批 (HITL)

当 LLM 节点启用了危险工具时，系统会弹出审批请求：

- 用户可以批准或拒绝每个工具调用
- 可以设置会话级放权，同一类型的工具后续自动批准
- 安全工具（读取文件、列出目录、网页搜索）默认自动执行

## 技术架构

### 前端

- 框架：React 19 + TypeScript + react-hook-form
- UI：Tailwind CSS + 自定义组件库
- 画布：React Flow（可交互的流程图引擎）
- 状态管理：Zustand（持久化）
- 构建：Vite + Electron

### 后端

- 运行环境：Electron Main Process 内嵌 Express 服务器
- 数据库：SQLite（Sequelize ORM + better-sqlite3）
- 向量存储：sqlite-vec 扩展，支持 10 种向量引擎
- AI 框架：LangChain + LangGraph（SQLite Checkpoint 持久化）
- LLM 缓存：自研 TTLCache，10 分钟过期
- 定时调度：自研三级时间轮，秒级精度

### 数据存储

所有数据保存在本地 SQLite 数据库中，包括：

- 工作流定义（节点、边、配置、环境变量）
- 技能和智能体配置
- LLM 配置（API 密钥、模型参数）
- 知识库分块数据 + 向量索引
- 对话历史和 LangGraph checkpoint
- 触发器配置与执行记录
- 全局环境变量
- MCP 服务器配置
- 模板种子数据

## 常见问题

### Q: 支持哪些 LLM 提供商？
A: 当前支持 OpenAI、Anthropic、Azure OpenAI、阿里百炼（Bailian）、DeepSeek、LongCat、Ollama（本地）。

### Q: 知识库支持哪些文件格式？
A: 内部知识库当前支持 txt 和 md 格式。上传后自动分块并生成向量索引。

### Q: 如何切换深色/浅色主题？
A: 在设置页面的「外观主题」标签中切换，所有界面元素统一适配。

### Q: 工作流数据如何备份？
A: 在设置页面的「数据管理」标签中可以导出所有工作流为 JSON 文件，也可以从 JSON 文件导入恢复。支持 VACUUM 回收数据库空间。

### Q: If 节点和 Branch 节点有什么区别？
A: If 节点使用 JS 布尔表达式判断，无需 LLM 参与，执行速度快。Branch 节点使用 LLM 对输入进行语义分析，适合需要理解语义的复杂条件。

### Q: 环境变量有什么作用？
A: 环境变量用于在模板中引用敏感信息（API Key、数据库连接串等），避免硬编码。工作流级 {{$env.xxx}} 仅当前工作流可见，全局级 {{$global.xxx}} 所有工作流共享。

### Q: LLM 缓存什么时候生效？
A: 仅在 LLM 节点勾选「启用缓存」后生效。相同 prompt 会在 10 分钟内直接返回缓存结果，不再调用 API。
