# AI Agent Flow Designer 产品文档

## 产品概述

AI Agent Flow Designer 是一款基于 Electron 的可视化工作流设计工具，旨在帮助用户通过拖拽节点的方式构建 AI Agent 工作流，无需编写代码即可实现复杂的自动化任务。

核心设计理念是「所见即所得」——用户在画布上连接各个节点，定义数据流向和处理逻辑，系统自动按流程执行并返回结果。

## 主要功能模块

### 工作流画布

画布是产品的核心交互区域，支持以下操作：

- 拖拽添加节点：从左侧工具栏拖拽节点类型到画布
- 连线：点击节点输出端口拖向另一节点输入端口，建立数据流
- 节点配置：双击节点打开配置面板，设置参数
- 一键布局：使用 dagre 算法自动排列节点位置，保持流程图清晰可读
- 缩放和平移：鼠标滚轮缩放，拖拽画布平移

### 支持的节点类型

| 节点类型 | 功能说明 | 颜色标识 |
|---------|---------|---------|
| 开始节点 (Start) | 工作流入口，接收用户输入 | 绿色 |
| 技能节点 (Skill) | 调用预定义的技能模板处理输入 | 黄色 |
| 分支节点 (Branch) | 根据条件判断选择不同执行路径 | 灰色 |
| API节点 (API) | 调用外部 HTTP API 获取数据 | 红色 |
| LLM节点 (LLM) | 调用大语言模型生成回复 | 蓝色 |
| Agent节点 (Agent) | 调用预配置的智能体执行任务 | 紫色 |
| CLI节点 (CLI) | 执行命令行指令或预设模板 | 橙色 |
| 结束节点 (End) | 工作流出口，返回最终结果 | 绿色 |

### LLM 节点配置

LLM 节点是使用最频繁的节点类型，支持以下配置项：

- 提示词模板：定义发送给 LLM 的提示词，支持变量插值 {{variableName}}
- 变量配置：定义模板中的动态变量，支持字符串、数字、布尔、数组类型
- 工具调用：勾选后 LLM 可自主调用文件读写、命令执行、HTTP请求、网页搜索等工具
- 知识库增强：启用后自动从知识库检索相关内容注入提示词，实现 RAG 检索增强
- 缓存开关：相同 prompt 重复调用时直接返回缓存结果

### 分支节点

分支节点支持多条件判断。系统会使用 LLM 对用户输入进行语义评估，匹配到哪个条件就走哪条路径。每个分支需要定义：

- 条件描述：用自然语言描述满足条件的情况，例如「用户询问价格相关信息」
- 条件标签：分支的显示名称

### CLI 节点

CLI 节点支持两种模式：

1. 自定义命令：直接输入 shell 命令，支持 {{input}} 变量替换
2. 预设模板：使用系统内置的文件操作模板（读取、写入、列表等），参数可配置

命令输出有两种处理方式：

- 原始输出：直接将 stdout/stderr 作为节点输出传递给下游
- LLM 处理：将命令输出交给 LLM 分析提取关键信息，可自定义处理提示词

### 知识库功能

知识库支持两种类型：

- 内部知识库：上传 txt/md 文档，系统自动分块、生成 embedding 向量、存入 sqlite-vec，检索时用向量相似度搜索返回最相关的片段
- 外部知识库：配置外部检索 API 地址和认证信息，直接调用第三方服务获取上下文

内部知识库的配置参数：

- 分块大小：文档切分的字符数（默认 500），影响检索精度和语义完整性
- 分块重叠：相邻分块的重叠字符数（默认 50），防止关键信息被切断在边界
- 检索数量 topK：每次查询返回的最大分块数（默认 3），影响注入上下文的丰富度

## 设置页面

设置页面分为四个标签页：

1. 模型配置：管理 LLM API 配置（提供商、密钥、模型、温度、最大 Token），支持多配置切换和连接测试
2. 知识库：管理内部/外部知识库，上传文档、查看分块统计
3. 外观主题：切换深色/浅色 UI 主题
4. 数据管理：导出/导入工作流数据

## 对话与执行

### 单次执行

点击工作流的运行按钮，输入文本后系统按节点顺序依次执行，最终返回结果。

### Agent 对话模式

为 Agent 配置一个工作流后，可以通过对话界面持续交互。系统会记住对话历史，支持多轮对话。对话中的附件（图片、文本文件）会被自动注入到 LLM 的输入中。

### 执行监控

执行过程中可以实时查看：

- 当前执行的节点
- 各节点的执行状态（运行中/完成/失败）
- 执行进度百分比
- 节点耗时和输出日志

### 工具审批 (HITL)

当 LLM 节点启用了危险工具（写入文件、执行命令、HTTP请求）时，系统会弹出审批请求：

- 用户可以批准或拒绝每个工具调用
- 可以设置会话级放权，同一类型的工具后续自动批准
- 安全工具（读取文件、列出目录、网页搜索）默认自动执行

## 技术架构

### 前端

- 框架：React + TypeScript
- UI：Tailwind CSS + 自定义组件库
- 画布：React Flow（可交互的流程图引擎）
- 状态管理：Zustand
- 构建：Vite + Electron

### 后端

- 运行环境：Electron Main Process 内嵌 Express 服务器
- 数据库：SQLite（Sequelize ORM + better-sqlite3 用于向量操作）
- 向量存储：sqlite-vec 扩展，支持 float32 向量相似度检索
- AI 调用：LangChain + LangGraph（带 checkpoint 持久化的多步骤执行）
- LLM 缓存：自研 TTLCache，10 分钟过期，避免重复调用浪费

### 数据存储

所有数据保存在本地 SQLite 数据库中，路径为用户数据目录下的 database.sqlite、knowledge.sqlite。包括：

- 工作流定义（节点、边、配置）
- 技能和智能体配置
- LLM 配置（API 密钥、模型参数）
- 知识库和分块数据
- 对话历史和 LangGraph checkpoint

## 常见问题

### Q: 支持哪些 LLM 提供商？
A: 当前支持 OpenAI、Anthropic、Azure OpenAI、阿里百炼（Bailian）、LongCat。所有提供商需兼容 OpenAI 消息格式。

### Q: 知识库支持哪些文件格式？
A: 内部知识库当前仅支持 txt 和 md 格式。上传后系统自动分块并生成向量索引。

### Q: 如何切换深色/浅色主题？
A: 在设置页面的「外观主题」标签中切换，所有界面元素包括画布节点颜色都会统一适配。

### Q: 工作流数据如何备份？
A: 在设置页面的「数据管理」标签中可以导出所有工作流为 JSON 文件，也可以从 JSON 文件导入恢复。

### Q: 分支节点如何工作？
A: 分支节点使用 LLM 对输入进行语义评估，根据自然语言条件描述匹配最合适的分支路径。条件描述越清晰，匹配越准确。

### Q: LLM 缓存什么时候生效？
A: 仅在 LLM 节点勾选「启用缓存」后生效。相同 prompt（不含工具和 HITL 的直接调用）会在 10 分钟内直接返回缓存结果，不再调用 API。
